# Quick Numbers (수 감각 훈련용 웹앱)

한국 초등학교 교실의 전자칠판 환경에 맞춰 제작된 수 감각(Subitizing) 훈련용 웹앱입니다.

## 기능 특징
- **다양한 교구 모드 지원**: 수 막대, 바둑돌, 십 배열표, 연결 막대
- **디테일한 노출 시간 설정**: 0.05초의 짧은 순간부터 1.5초 이상까지 자유롭게 조절
- **수업 최적화**: 
  - 전자칠판 오작동 방지를 위한 전체 화면 우클릭 방지
  - 멀리서도 잘 보이는 큼직한 레이아웃 (반응형 100dvh)
  - 다크/라이트 모드 지원
  - 정답 공개 시 효과음 및 애니메이션

## 사용법
별도의 설치 과정 없이 웹 브라우저에서 `index.html`을 열어 바로 실행할 수 있습니다. 
(크롬, 엣지, 사파리 등 모던 브라우저 권장)
